Mini-Projeto — Sequência de Collatz (JavaScript)

Objetivo: praticar ciclos (for, while) e listas (arrays), organizando o código em funções.

Contexto

A sequência de Collatz começa num número inteiro positivo n e evolui segundo as regras:

  • se n é par → n = n / 2
  • se n é ímpar → n = 3n + 1

A sequência termina quando se atinge o valor 1.

Exemplo: n = 6 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1

Parte A — Cálculo da sequência (nível base)

Tarefa A1 — Validar o input
  • Ler um número inteiro introduzido pelo utilizador.
  • Se o valor não for um inteiro positivo válido, mostrar uma mensagem de erro.
  • Caso contrário, continuar.
Tarefa A2 — Gerar a sequência
  • Calcular a sequência completa de Collatz a partir do número introduzido.
  • Usar um ciclo while.
  • Guardar todos os valores da sequência numa lista (array).
  • A sequência deve incluir o valor inicial e terminar em 1.
Tarefa A3 — Mostrar resultados
  • Mostrar no ecrã a sequência completa.
  • Mostrar o número de passos necessários para chegar a 1.

Parte B — Análise da sequência (listas + ciclos)

Tarefa B1 — Maior valor atingido
  • A partir da lista da sequência calculada, determinar o maior valor atingido.
  • Mostrar esse valor ao utilizador.
Regra: não usar funções automáticas para encontrar o máximo. Deve ser feito com um ciclo.
Tarefa B2 — Histórico (lista de listas)
  • Guardar todas as sequências calculadas com início menor que 500 numa lista global.
  • Cada sequência deve ser guardada como uma lista dentro de outra lista.
  • Não devem ser guardadas sequências repetidas (com o mesmo valor inicial).

Parte C — Representação gráfica (listas de listas)

Tarefa C1 — Desenhar as sequências
  • Desenhar um gráfico onde cada sequência guardada é representada por uma linha.
  • Eixo horizontal: número do passo.
  • Eixo vertical: valor da sequência.
Tarefa C2 — Atualizar o gráfico
  • Sempre que uma nova sequência válida for calculada, o gráfico deve ser atualizado.
  • Todas as sequências anteriores devem continuar visíveis.

Parte D — Análise global (desafio)

Tarefa D1 — Calcular comprimentos (2 a 500)
  • Para todos os números de 2 a 500, calcular o comprimento da sequência de Collatz correspondente.
Tarefa D2 — Guardar resultados numa lista

Guardar os resultados numa lista de forma adequada, por exemplo:

início → comprimento 2 → 2 3 → 8 4 → 3 ...
Tarefa D3 — Encontrar o maior
  • Determinar qual o número entre 2 e 500 que gera a sequência mais longa.
  • Mostrar também o comprimento dessa sequência.
Tarefa D4 — Gráfico de comprimentos
  • Desenhar um gráfico onde:
  • Eixo horizontal: número inicial.
  • Eixo vertical: comprimento da sequência.

Regras gerais

  • Usar apenas ciclos for e while e listas (arrays).
  • Evitar funções “automáticas” que façam o trabalho todo.
  • Organizar o código em funções pequenas e claras.
  • O programa não deve entrar em ciclos infinitos.

Desafio extra (opcional)

  • Guardar resultados já calculados para acelerar o programa (memoização).
  • Calcular a média dos comprimentos das sequências entre 2 e 500.
  • Mostrar os 10 números que originam as sequências mais longas.
